# 中文技术报告演示稿

1. **确定底稿。** 编辑或续写时从目标 PPTX 开始，使用用户指定的参考版式。新建且没有指定模板时，复制随技能提供的 [可编辑参考 PPTX](assets/zh-technical-report.pptx)。路径相对于技能目录解析。参考稿中的示例文字和图形用于演示排版，选用所需页型后换成当前主题的内容。
2. **安排讲述顺序。** 从具体场景进入，再按「输入 → 判断 → 可观察结果」解释机制。每页回答一个问题，先说清动作，再引入术语。区分公开实现、已测结果和拟议方案。按用户指定的页数和图数组织内容，封面计入总页数。
3. **让图承担解释。** 用带标注的论文原图讲机制，用真实源码节选定位关键判断，用可编辑示意图讲流程或自己的方案。按需要阅读 [版式、用图和检查规范](references/layout-and-evidence.md)，查看参考稿里对应的页型。
4. **检查交付稿。** 使用当前环境可用的 PPTX 工具，保留标题、正文和自绘图的可编辑性。导出后逐页渲染，检查模板一致性、可读性、图文标注对应和来源。追加页时对照原稿核对保留页。交付时说明实际完成的验证。
