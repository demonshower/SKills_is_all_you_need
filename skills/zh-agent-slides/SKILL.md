# 中文技术报告 PowerPoint

## 选模板与版式

- 优先使用用户当次指定的模板。改版时，以上一版已获认可的 PPTX 为起点。两者均未提供时，默认查找 `C:/Users/Administrator/Desktop/智能体论文分享1.pptx`。默认文件缺失时，采用下述白底、深绿和黑字的版式，标识使用用户提供的素材。
- 先渲染并查看代表页，确认尺寸、母版、版式、占位符、标识与页码。复用可编辑结构。以模板制作新稿时另存文件。只要求追加时，核对原页的文字和渲染结果。
- 默认模板为 16:9 白底、深绿页眉线、校徽、实验室标识和页码，使用微软雅黑。封面保留居中大标题、短副题和日期，标题的红色强调沿用模板。正文用黑字，深绿 `#0B5128` 用于小标题、项目符号和重点标注。
- 灰字 `#696969` 只用于单独成行的例子或比方，以「例如」或「比如」开头。正文、图注、页脚使用黑或深绿。保留论文原图和源码界面的必要配色。
- 按模板标题比例排版。默认正文约 21 pt，图文并排约 19–21 pt，例子约 18–20 pt。对齐左边线，给段落和图注留空间。内容装不下时先拆页或精简。避开渐变、阴影、夸张圆角和装饰性卡片。

## 按读者的问题组织内容

- 封面交代主题。背景页用一个真实场景讲清问题。方法页按步骤讲清谁读取什么、在哪一步作出判断、执行后发生什么。对照页沿同一问题比较各实现。
- 实验页明确任务、对照、动作和观察指标。把「公开实现」「已测结果」「拟议机制／实验」写在相应页或图上。结论页用一句可验证的判断收束。
- 标题直接说本页讲的事，绿色小标题给出具体结论。每个要点先用白话交代动作，再引入必要术语。举例用真实的文件、请求、参数或观察结果。讲 Agent 安全时，分别交代什么被写入或召回、模型看到什么、谁最终放行或拒绝。
- 用户指定总页数时，封面计入总数。图文扩版可以把原来塞在一页的实现、案例和实验拆开，一页讲一个问题。十页左右的图解稿可用 4–8 幅有效图，按内容和当次要求调整。

## 选图、标图和放图

- **论文原图。** 选能解释核心机制的原图或相关分图，保留原始比例、关键标签和完整语义。用少量绿色圈号或框指出关键位置，旁边用对应编号解释该步骤。短图注写明论文和图号。
- **源码截图。** 从官方仓库或已核验的本地检出读取真正执行关键动作的几行。保留文件名和真实行号，跳过的行用省略标记。可将真实源码重新排版成清晰截图，标为「源码节选」。高亮准入判断、权限检查或关键字段，让正文的编号与代码对得上。
- **自绘示意图。** 没有合适原图或需要解释自己的机制时，优先用 PowerPoint 可编辑形状画流程、条件树或请求路径。箭头标真实的顺序或依赖。用图上标签区分示意、拟议和实测。
- 图复杂时用宽图配短解释。源码可与两三个要点并排。保持图文留白与图中文字可读，正文一眼能找到对应的高亮。图注保持简短，把链接、版本或提交、文件与行号放进该页演讲者备注。

## 检查并交付

- 使用可用的 Presentations 工作流制作并导出本地 PPTX。把原始素材和中间文件放在当前任务允许的工作目录。正文、页标题和自绘图保留可编辑性。
- 对导出的 PPTX 逐页渲染，能用 PowerPoint 原生渲染时优先用它做终检。检查母版和标识、对齐与间距、中文断行、字号、灰字用途、图文重叠、裁切、图中高亮及编号对应。修正后重渲染受影响的页。
- 核对总页数、关键图数、图源与备注、公开实现和研究提案的标识。交付 PPTX，并简要说明主要改动和实际完成的检查。
