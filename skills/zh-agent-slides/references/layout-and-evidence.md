# 版式、用图和检查规范

## 使用参考稿

[参考 PPTX](../assets/zh-technical-report.pptx) 采用 16:9 白底和深绿页眉，可复制其中需要的页。用户指定模板时，尺寸、母版、字体、配色和标识以该模板为准。制作新稿时保留参考文件，另存工作副本。默认参考稿的页码是可编辑的，重排后按实际顺序更新。

| 页型 | 参考页 | 内容组织 |
| --- | --- | --- |
| 封面 | 1 | 居中主标题、短副题和报告人或日期。 |
| 机制或案例 | 2 | 黑色标题、绿色要点，用具体输入、判断和结果讲清动作。 |
| 源码或细节图 | 3 | 图文并排，用圈号把旁边的解释与高亮对上。 |
| 流程或论文原图 | 4 | 将关键证据放大，保留足够空间写一句读图提示和图源。 |
| 实验或对照 | 5 | 一侧写对照条件，另一侧写指标。结果页换成真实数值或图表。 |
| 结论 | 6 | 用观察、证据和适用范围收束。 |

默认正文用黑字，深绿 `#0B5128` 用于小标题和标注。灰字 `#696969` 只给单独成行的例子或比方，以「例如」或「比如」开头。参考稿使用 Microsoft YaHei，跨平台时可选环境已安装的思源黑体或 Noto Sans CJK SC，换字后重查中文断行。正文约 19–21 pt，主标题约 36 pt。统一左边线与图注位置，预留安全边距。内容拥挤时先拆页或精简，避免装饰性渐变、阴影和卡片墙。十页左右的图解稿可参考 4–8 幅图，按论证需要调整。

## 用图和标注

- **论文原图**。优先选择能直接解释本页判断的原图或分图，保留比例、坐标、图例和结论所需的上下文。用少量圈号或框指向关键位置，编号和正文对应。图注写论文简称及图号。
- **源码节选**。从已核验的版本取实际执行路径，保留文件名、行号和原有代码，省略行单独标明。可以重排成清晰截图，注明「源码节选」。高亮真正作出判断或产生效果的行。参考稿第 3 页用可编辑的示意代码演示标法。
- **自绘图**。用可编辑形状表示步骤、条件或数据流。箭头表达真实的顺序或依赖。根据内容标明示意或拟议方案。图上文字优先使用读者能看到的对象与动作。
- **来源**。将论文链接、图号、仓库版本或提交、文件与行号放在该页演讲者备注。图上保留简短出处。示意图如根据其他材料改绘，注明依据。

## 交付前检查

- 核对页数、用户要求的图数、每页的问题与结论。指标标出量纲、对照条件和数据来源。
- 用可用的 PPTX 渲染器逐页查看导出稿。检查页眉、对齐、字体、断行、重叠、裁切、图的比例、标记与说明的对应关系。修改后重渲染受影响的页。
- 如果可用环境只能检查文件结构，明确说明视觉检查尚未完成。续写时核对原页内容及视觉布局，再确认新增页沿用同一版式。
